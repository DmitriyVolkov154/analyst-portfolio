# Marketplace Order

Учебный проект системного аналитика по проектированию процесса заказа товара на маркетплейсе.

## Цель проекта

Спроектировать основные бизнес-процессы и системное взаимодействие участников при создании, оплате и доставке заказа.

## Участники

- Customer — покупатель
- Seller — продавец
- Order Service — управление заказом
- Payment Service — обработка платежа
- Delivery Service — доставка заказа
- Marketplace — клиентское приложение и бизнес-логика маркетплейса
